# Mental model

[CLAUDE.md](../CLAUDE.md) is the single source of truth for working in this repository: the truth hierarchy between the specification corpus and the code, the guardrails that apply to every change, the two routing tables naming which files, specifications, and tests a given change must open, and what counts as done.

The specification corpus is [`spec/`](../spec/README.md), a directory of short documents with an explicit authority model, not a single file.

Read CLAUDE.md first. Nothing is repeated here, so anything you find only in this file is out of date.
